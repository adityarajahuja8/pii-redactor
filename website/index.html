Overview

Hybrid Architecture (Regex + spaCy NER)

Reads a .docx document (paragraphs, 76 tables, headers, footers), detects PII using a hybrid approach, replaces matched PII with deterministic MD5-seeded fake values, and outputs a formatted redacted document.

🔍 Hybrid Detection

Regex for structured PII (emails, phones, CIN, PAN, IP). spaCy NER + custom heuristics for unstructured names and addresses.

🔄 Deterministic Pseudonymisation

MD5-seeded Faker ensures "Sarthak Malvadkar" always maps to "Priya Kakar" across all paragraphs and tables.

📐 Run-Level Docx Editing

Operates at the XML run level so bolding, italics, fonts, and table styling remain completely intact.
